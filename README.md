## 绿云vps是什么来头

GreenCloudVPS 是 2013 年成立的老牌海外 VPS 商家，机房覆盖北美、欧洲、亚太，不同统计口径在 23 到 31 个位置之间。官网页面上挂着 LowEndTalk 社区评选的 "#1 Top Provider" 和 "#1 Most Stable Provider" 两个标签，这是社区投票性质的评价，参考即可，别当 SLA 看。

它家所有套餐都是 unmanaged：给你 root 权限，系统装好之后自己维护。没有免费套餐，也没有按小时计费，都是整月起步。控制面板是 Virtfusion（部分页面写 Cloud Control Panel），支持重装系统和电源管理，每个套餐默认带 1 次免费备份/快照。

需要说清楚的一点：默认带 1 次备份快照，但按第三方功能对比站的统计，绿云没有提供自动定期备份功能。看重备份的，要么自己写脚本，要么接受这个短板。

## 东京、香港、新加坡实测数据：选机房不能只看价格

绿云的机房表现差异很大，这一点社区实测说得比官方页面直白得多。有用户在 NodeSeek 论坛发布过存储型促销方案（$168/3 年，约 $4.7/月）的四节点实测，几个数据点值得参考：

- **东京软银**：IPv4 回程三网走软银，电信延迟 43ms，国内访问体验最好；但 IP 被墙风险高，换 IP 收 $2，IPv6 绕美延迟 280–395ms、基本不可用，且经常缺货。
- **东京 IIJ**：性能平庸，线路和 IP 干净，IPv6 走 IIJ 直连可用。该帖作者的判断是：面向国内访问，这是唯一合理的选择。
- **纽约 NYC2**：CPU 单核跑分 1003，比第二名高 28%，内存带宽翻倍，流量给 8TB；但系统盘被限速到 193MB/s。
- **新加坡**：CPU 全场最弱（多核比纽约低 30%），数据盘反而最强（顺序读 2070MB/s、1 万 IOPS），流量进出合计；IPv4 美区流媒体全解锁。

各节点都能解锁 ChatGPT、YouTube、TikTok，Netflix 基本只有自制剧。

更早的社区评测归纳过整体格局：美国拉斯维加斯、日本东京、香港表现靠前，美西和新加坡次之，美国中东部和欧洲机房主要服务当地用户。东京促销款早年还有 Ryzen 9 5950X + NVMe 的配置，三网直连，但晚高峰丢包偏高——这个特点在多篇评测里反复出现，可以说是绿云亚太机房的通病。

## 买绿云前最该想清楚的三件事

1. **付款周期宜短不宜长。** 官网没有公示各套餐续费价，国内测评站也提醒过绿云“续费价格方面有过背刺老用户的情况”。月付最稳，年付只在你确定长期用、且接受价格变动风险时再考虑，三年付这类长周期活动要当作“不可退款的一次性消费”来评估。
2. **流量按机房口径算。** 亚太减半、存储促销进出合计，口径不止一种。顺带提醒一个容易混淆的数字：新加坡 DC1 促销位 4GB 内存的 "-2" 档流量是 750GB，和 SSDKVM-1 亚太机房的 750GB 数值撞车但完全是两个产品，下单前对清楚自己买的是哪一个。
3. **unmanaged 意味着自担运维。** 工单 24/7 有，但系统层面的问题得自己解决，没有运维经验的话，先把重装和备份快照玩熟。
